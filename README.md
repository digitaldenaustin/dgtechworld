# dgtechworld

Digital Den Austin marketplace starter built with Next.js, TypeScript and Tailwind CSS.

## Phase 1 included
- Mobile-first storefront
- Live inventory page
- Individual product pages
- Four current inventory items
- SEO metadata
- Vercel-ready project structure
- Supabase packages installed for the next phase

## Local development
```bash
npm install
npm run dev
```

## Environment setup
Copy `.env.example` to `.env.local` when Supabase integration begins.

## Deployment
Connect this GitHub repository to Vercel. Every push to `main` will create a production deployment.
